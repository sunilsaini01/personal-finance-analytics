# Code of Conduct

## Our Commitment

This project welcomes contributions and discussion from anyone, regardless of experience level, background, or identity. As maintainer, I'm committed to keeping this a respectful, harassment-free space for everyone who participates — through issues, pull requests, code review, or any other project interaction.

## Expected Behavior

- Be respectful and constructive in feedback, especially in code review.
- Assume good faith; ask clarifying questions before assuming bad intent.
- Give specific, actionable critique ("this join will fan out because X" beats "this is wrong").
- Respect that this started as a solo learning/portfolio project — some design decisions are documented and deliberate (see [`docs/14_ER_Diagram_Architecture.md`](docs/14_ER_Diagram_Architecture.md) and [`docs/00_PRD_Scope_Addendum.md`](docs/00_PRD_Scope_Addendum.md)); disagreement is welcome, but read the rationale first.

## Unacceptable Behavior

- Harassment, insults, or personal attacks, in any project space (issues, PRs, commit comments).
- Discriminatory jokes or language.
- Publishing others' private information without consent.
- Sustained disruption of discussion or review.

## Scope

This Code of Conduct applies within all project spaces (this repository's issues, pull requests, and discussions) and in any other setting where an individual is representing the project.

## Enforcement

Instances of unacceptable behavior may be reported by opening an issue or contacting the maintainer directly. Reports will be reviewed and addressed as appropriate to the situation, which may include a warning, temporary restriction, or removal from project spaces.
